## C) Comprobaciones estructurales

- /panel -> HTTP 200 (curl), HTML contiene id= roleCard/websiteCard/socialCard/reputationCard/subscriptionCard/dataCard/auditCard (5 match de secciones nuevas).
- role="alert" presente para errores de cada sección; role="status" para confirmaciones.
- Ninguna sección muestra error 403 en los dumps (los permisos usados por cada card
  se comprueban contra /me antes de renderizar; si una API deniega, se muestra alerta visible).
