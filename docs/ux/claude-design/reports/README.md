# Reportes y evidencias de diseño

Claude Design puede guardar aquí **toda evidencia útil de UX/UI**: `PROGRESS.md`, `QA.md`, `HANDOFF.md`, capturas de pantalla sanitizadas, comparativas visuales y observaciones de pruebas.

Guía de calidad de los reportes:
- Ser **breves, verificables y útiles** para el propietario y SOL MAIN.
- Señalar qué se probó realmente en navegador, con viewport y resultado, y qué solo está simulado.
- Usar únicamente datos ficticios; no añadir credenciales, capturas de cuentas reales ni información privada.
- Referenciar commit/ruta de los archivos comprobados.
- No crear una aprobación formal para cada ajuste de interfaz.

El reporte de avance vigente está en [PROGRESS.md](PROGRESS.md).
