# Trabajo en progreso de Claude Design

Esta carpeta está autorizada para **exploración, experimentos y versiones intermedias** de la experiencia de MainSpot: variantes visuales, componentes, maquetas, prototipos parciales, tokens, assets y notas útiles.

Puedes hacer **commit y push** de este trabajo a la rama autorizada y actualizarlo sin pedir permiso por cada iteración.

Evita datos reales, credenciales y dependencias instaladas. La versión que revisará el propietario se entrega en `../deliverables/`, no aquí.
