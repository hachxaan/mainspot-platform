# TR-0003 — Riesgo técnico

## Risk
Con el token comprometido, un tercero puede enviar mensajes o consumir actualizaciones (y perder acuses), pero no puede producir callbacks firmados sin la clave de acuse ni pasar por el usuario autorizado. Mitigación: rotar el token y la clave; el vencimiento detecta la falta de acuse.
