# SEC-0001 — Modelo de amenazas del AI Core y pruebas negativas obligatorias

| Amenaza | Vector | Control | Prueba |
|---|---|---|---|
| Cruce de tenant | herramienta del asistente, asset id, invocación | tenant de la sesión en cada consulta; anti-oráculo 404 | E03, E11, E16 |
| Escalada de rol | token de negocio contra API de plataforma | audiencia y clave HMAC distintas; tablas separadas | E03, E17 |
| Robo de sesión de plataforma | contraseña filtrada | MFA TOTP, anti-replay del paso, sesión 30 min, step-up 10 min | E17 |
| Prompt injection | comentario/reseña/mensaje | datos delimitados y JSON-codificados; herramientas fijas por caso de uso; sin herramientas de mutación | E16 |
| Exfiltración de secretos | prompt, traza, respuesta | secretos solo como `secret_ref`; escáner de salida para patrones de claves | E16 |
| XSS en sitio | DSL con HTML | escape total, CSS solo desde tokens validados, CSP sin scripts | E16 |
| SSRF | URL sugerida por el modelo | el servidor no descarga URLs del modelo; imágenes solo del proveedor configurado | E16 |
| Envenenamiento de marca | IA o tercero escribe hechos | IA solo propone `unconfirmed`; confirmar exige rol | E01 |
| Abuso de costo | bucle de generación | rate limit por usuario, presupuesto con reserva y techo duro | E15 |
| Doble respuesta/publicación | reintentos y dos vías | ledger único, idempotencia, reconciliación de inciertos | E14 |
| Configuración maliciosa/rota | ruta mal formada | validación al crear; activación solo de rutas evaluadas; rollback | E04, E18 |
| PII en trazas | logs | hash de entrada, sin texto completo, redacción en errores | E16 |
