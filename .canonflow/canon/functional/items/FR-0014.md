# FR-0014 — Diseño y edición web generativos con preview, aprobación y versiones

## Statement
«Crea mi página» produce un **diseño personalizado** por negocio: arquitectura de secciones, copy, paleta y
tipografía, imágenes y SEO básico honesto. El modelo no escribe HTML/JS libre: devuelve un **DSL de bloques
verificados** que el servidor valida y renderiza con escape, CSS derivado de tokens validados y **sin JavaScript**
en el sitio. Teléfono, dirección, horario y precios provienen de hechos confirmados, nunca del modelo.

Ediciones: una edición **simple** (texto, dato, estilo puntual) usa la ruta económica y devuelve un **parche tipado**
que solo toca las rutas solicitadas; una edición **compleja** (rediseño, reestructura) usa la ruta de mayor
capacidad. La clasificación simple/compleja la da Jev; si Jev no está disponible se usa la ruta compleja
(calidad antes que ahorro) y se registra.

Todo cambio genera diff semántico y vista previa visual (antes/después), requiere aprobación de Administración y se
publica como **versión nueva inmutable**. Restaurar v1 después de v2 crea v3 (FR-0007 / DEV-E2E-04).

## Calidad exigida (no basta HTTP 200)
- Responsivo a 360, 768 y 1440 px sin desbordamiento horizontal.
- Contraste de texto AA (≥ 4.5:1) calculado sobre la paleta final; ajuste automático registrado.
- Landmarks semánticos, un `h1`, ALT en toda imagen, idioma declarado, enlace «saltar al contenido».
- Diseño distinguible entre negocios (variantes de bloques, paleta y tipografía).

## Acceptance criteria
| id | given / when / then |
|---|---|
| AC-14001 | Given un negocio con hechos confirmados, when pide su primera página, then recibe una vista previa con diseño propio e imágenes etiquetadas, y nada se publica sin aprobación. |
| AC-14002 | Given «cambia el horario del sábado», when se procesa, then la ruta usada es la económica y el diff solo contiene esa ruta del documento. |
| AC-14003 | Given un diseño con texto que intenta inyectar `<script>`, when se renderiza, then aparece escapado y la página no ejecuta JavaScript. |
| AC-14004 | Given una publicación aprobada, when se sirve por HTTPS local, then el HTML es el de la versión aprobada y supera los criterios de calidad. |
