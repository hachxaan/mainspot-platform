# NFR-0007 — Estado de avisos y acuses durable, local e independiente de PostgreSQL

## Statement
Eventos, recibos, acuses y cursor se guardan en almacenamiento local privado con escritura atómica y bloqueo de un único consumidor, sobreviven a reinicios y no dependen de la base de datos que los avisos vigilan.

## Acceptance criteria
| id | given / when / then |
|---|---|
| AC-9171 | Given un fallo entre persistir el acuse y avanzar el cursor, when se reanuda, then el acuse persiste y la redelivery es idempotente. |
| AC-9172 | Given dos consumidores simultáneos, when el segundo arranca, then se niega sin procesar actualizaciones. |
