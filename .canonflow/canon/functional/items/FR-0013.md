# FR-0013 — Brand Studio, hechos verificados y biblioteca multimedia

## Statement
Cada negocio mantiene una **memoria comercial versionada**: nombre, giro, descripción, propuesta de valor, voz,
audiencia, idioma, tonos a evitar, paleta, tipografía permitida, productos/servicios, ubicaciones, horario, canales,
llamadas a la acción, precios confirmados, promociones con vigencia y restricciones. Cada hecho guarda **origen**
(dueño, importado, sugerido por MainSpot), fecha, aprobación y nivel de confianza (`confirmed`, `unconfirmed`).

La IA solo usa hechos **confirmados** como hechos; los no confirmados pueden inspirar redacción pero nunca se
presentan como datos (precio, horario, dirección, teléfono, promoción). Cada herramienta recupera solo las claves
que necesita. Un cambio de hechos marca como desactualizados los borradores que dependían de la versión anterior y
ofrece regenerarlos; nunca sobrescribe en silencio lo ya aprobado o publicado.

La **biblioteca multimedia** guarda imágenes generadas o subidas con origen, licencia/consentimiento, ALT,
dimensiones, variantes por formato, huella y estado. Una ilustración generada se etiqueta como tal; no se presenta
como fotografía real de instalaciones o productos.

## Acceptance criteria
| id | given / when / then |
|---|---|
| AC-13001 | Given un hecho de precio no confirmado, when la IA genera una página o publicación, then el precio no aparece en el resultado. |
| AC-13002 | Given un borrador generado con la versión N de la marca, when el dueño confirma un cambio (versión N+1), then el borrador se muestra como desactualizado con opción de regenerar y la publicación aprobada no cambia. |
| AC-13003 | Given una imagen generada, when se guarda, then tiene ALT, licencia, modelo de origen, invocación y etiqueta de ilustración; es reutilizable en web y social. |
| AC-13004 | Given otro tenant, when pide un asset ajeno por su id, then obtiene la misma respuesta que para uno inexistente. |
