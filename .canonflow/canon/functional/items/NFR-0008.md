# NFR-0008 — Metas cuantitativas por caso de uso

## Statement
Metas **provisionales** fijadas antes de implementar; no hay baseline previo de IA generativa en MainSpot. Se
recalibran con las mediciones de las evaluaciones F1/F6 y el resultado medido se publica junto a la meta. Una suite
automatizada al 100 % no equivale a calidad visual o creativa: esta requiere rúbrica humana (propietario).

| Caso de uso | Validez estructural | Fidelidad | Latencia P95 | Costo por artefacto |
|---|---|---|---|---|
| conversation.intent.classify (Jev) | 100 % contrato | intención ≥ 90 % y 0 fallos de riesgo (DEC-0031); sentimiento ≥ 85 % incl. ironía/negación/mixto | ≤ 10 s | ≤ USD 0.001 |
| website.initial.design (+3 imágenes) | ≥ 95 % al primer intento, ≥ 99 % con 1 reparación | 0 precios/teléfonos/promos inventados | ≤ 180 s | ≤ USD 0.35 |
| website.edit.simple | ≥ 98 % | 0 cambios fuera de lo pedido | ≤ 20 s | ≤ USD 0.01 |
| website.edit.complex | ≥ 95 % | 0 hechos inventados | ≤ 90 s | ≤ USD 0.10 |
| social.facebook.post.compose | ≥ 98 % | 0 ofertas inventadas; ≤ 3 emojis y ≤ 4 hashtags por variante | ≤ 30 s | ≤ USD 0.02 (+ imagen ≤ USD 0.06) |
| engagement.*.reply | ≥ 98 % | solo hechos verificados | ≤ 20 s | ≤ USD 0.005 |
| conversation.owner.assistant | ≥ 98 % | 100 % de cifras trazables a herramientas; 0 cruces de tenant | ≤ 30 s | ≤ USD 0.02 |
| marketing.campaign.plan | ≥ 95 % | 0 acciones de gasto | ≤ 60 s | ≤ USD 0.05 |
| business.insights.generate | ≥ 95 % | abstención con datos insuficientes; periodo citado | ≤ 45 s | ≤ USD 0.02 |

UX propietario (móvil 360–414 px): sin desplazamiento horizontal, objetivos táctiles ≥ 44 px, una acción
principal por pantalla, sin jerga técnica (léxico vigilado: «prompt», «modelo», «token», «API», «JSON»).
Accesibilidad de sitios publicados: AA de contraste, ALT, landmarks y `lang`.
