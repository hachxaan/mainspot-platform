# FR-0019 — MainSpot Engineering Console: prompts, rutas, evaluaciones y despliegue sin código

## Statement
Interfaz para ingeniería (rol `ai_engineer`) que gestiona la IA **sin editar archivos ni redeploy**:

- **Catálogo** de casos de uso con estado, ruta/modelo/prompt activos, costo, latencia y errores recientes.
- **Prompt Studio**: system y task separados, variables tipadas en lista blanca, versiones **inmutables** con hash,
  diff, nota de cambio y vista del prompt final sanitizado. El preámbulo de seguridad de plataforma no es editable.
- **Modelos y rutas**: proveedores con referencia a secreto (nunca el valor), prueba de conectividad, modelos por ID
  exacto con precio y fecha de origen; ruta por caso de uso con parámetros, timeout, reintentos, límite de costo.
- **Evaluaciones**: suites sintéticas por caso de uso, comparación A/B de rutas con calidad, validez, costo y latencia.
  Las suites se conservan; DEC-0074 no ordena ejecutarlas desde el agente ni repetir las baterías generativas.
- **Laboratorio y evidencia manual (DEC-0074)**: vista `/ingenieria#/laboratorio` para emitir y revocar grants de
  laboratorio (negocio + usuario + rutas DRAFT permitidas + plazo + motivo, con step-up), con costos y controles
  visibles. Por ruta, **evidencia manual**: lista de invocaciones reales `manual_lab` (id, negocio, actor, estado,
  proveedor/modelo, costo, latencia, hash de salida; sin texto de clientes ni salidas crudas) y **revisión manual**
  con selección de invocaciones, checklist (`result_reviewed`, `task_fit`, `safety_privacy`, `cost_acceptable`),
  notas y decisión aceptar/rechazar → «Registrar revisión» con step-up. Aceptar (todo el checklist en verdadero, evidencia real,
  exitosa, no simulada, de la misma ruta/prompt/caso de uso, con costo trazable) marca DRAFT → TESTED y guarda un
  registro de revisión manual propio con snapshot, hash, actor, notas y fechas; nunca crea una ejecución de
  evaluación ni un PASS de calidad. Rechazar no marca TESTED. Ni aceptar ni rechazar aprueban, promueven ni activan.
- **Ciclo de vida**: DRAFT → TESTED → APPROVED → CANARY → ACTIVE → RETIRED; activación atómica, canary por
  porcentaje, **rollback inmediato**, historial append-only con actor/motivo/hash. Una ejecución iniciada conserva
  la versión con la que empezó. TESTED tiene dos orígenes distinguibles en la ruta: evaluación de suite PASS o
  revisión manual aceptada (`tested_manual_review_id`). `APPROVED` es un estado global (paso separado con step-up),
  pero el despliegue (canary/activa, con motivo y step-up) de una ruta cuya evidencia es solo revisión manual se
  admite únicamente en el entorno `lab`; producción exige suite PASS.
- **Operaciones**: trazas sanitizadas, costo y tokens por negocio/caso/modelo, fallos e incertidumbre.

## Acceptance criteria
| id | given / when / then |
|---|---|
| AC-19001 | Given una versión nueva de prompt con eval aprobada, when se activa en canary 50 % y luego al 100 %, then nuevas ejecuciones usan la nueva versión sin redeploy y la traza lo muestra. |
| AC-19002 | Given una ruta activa, when se hace rollback, then la siguiente ejecución usa la ruta anterior y el historial conserva ambas. |
| AC-19003 | Given una ruta sin evaluación aprobada (ni, solo en `lab`, revisión manual aceptada según DEC-0074), when se intenta aprobar o activar, then se rechaza. |
| AC-19004 | Given un job en curso, when cambia la ruta activa, then el job termina con la versión fijada al inicio. |
| AC-19005 | Given una ruta DRAFT y `AI_ENVIRONMENT=lab`, when un usuario de negocio invoca sin grant seleccionado y vigente para esa ruta (o con grant caducado/revocado/de otro negocio o usuario), then la invocación no ejecuta la ruta DRAFT y no cae a otro proveedor; con grant válido ejecuta la ruta pinned, registra `assignment=manual_lab` y el id del grant, y descuenta de los presupuestos vigentes (DEC-0074). |
| AC-19006 | Given invocaciones reales `manual_lab` exitosas de una ruta DRAFT, when el revisor con step-up acepta con el checklist completo, then la ruta pasa a TESTED con `tested_manual_review_id`, no existe ninguna ejecución de evaluación nueva, la ruta sigue sin aprobar ni activar, y su despliegue (canary/activa) fuera de `lab` se rechaza aunque llegue a `APPROVED` (DEC-0074). |
