# FR-0015 — Publicaciones de Facebook generativas y calendario editorial

## Statement
«Anuncia la promoción vigente» lee **solo promociones confirmadas y vigentes**; genera 2–3 variantes de copy con
emojis moderados, CTA y hashtags útiles, y una propuesta visual (imagen generada o de la biblioteca). El dueño elige,
regenera parcialmente o edita; la vista previa reproduce el formato del canal. La aprobación cubre texto + imagen +
fecha + Page y entra al **scheduler durable existente** (DEV-E2E-04). Sin conexión Meta autorizada la publicación
queda simulada y etiquetada; un scheduler con Meta falso **no** acredita publicación real.

El **calendario editorial** propone ideas fechadas a partir de hechos aprobados (estacionalidad o eventos solo si son
verificables), con frecuencia elegida por el dueño, detección de publicaciones casi duplicadas y aprendizaje por
rechazo/edición. Nunca publica sin aprobación ni inventa ofertas o resultados.

## Acceptance criteria
| id | given / when / then |
|---|---|
| AC-15001 | Given una promoción no confirmada o vencida, when se pide anunciarla, then no se genera copy con esa oferta y se explica por qué. |
| AC-15002 | Given variantes aprobadas con imagen y fecha, when llega la hora, then el scheduler publica una sola vez y el resultado incierto se reconcilia antes de reintentar. |
| AC-15003 | Given un texto casi idéntico a una publicación reciente, when se propone, then se advierte del duplicado. |
