# FR-0012 — Aviso del productor por el bot exclusivo, en la misma ejecución y sin éxito falso

## Statement
Cada evento notificable del productor de respaldos remotos (E-SIZE-LIMIT, aviso del 80 % y códigos de §13 con «Aviso: sí») se entrega por el bot de Telegram exclusivo del productor en la misma ejecución que lo detecta, con un intento acotado; si Telegram no está disponible el evento se conserva para reintentos controlados y seguimiento, sin bloquear el respaldo y sin registrar como exitosa una entrega fallida.

## Acceptance criteria
| id | given / when / then |
|---|---|
| AC-9121 | Given Telegram no disponible, when el productor emite E-SIZE-LIMIT, then la ejecución termina en tiempo acotado, el evento queda pendiente y el registro no muestra éxito. |
| AC-9122 | Given un evento ya aceptado por la API, when se reintenta el mismo event_id, then no se envía un segundo mensaje. |

## Notes / rationale
DEC-0064 (canal), DEC-0065 §§ entrega en la misma ejecución, reintentos controlados, sin éxito falso; DEC-0061/DEC-0063 (E-SIZE-LIMIT inmediato). Epistemic state: DECIDED.
