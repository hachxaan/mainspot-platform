# FR-0012 — MainSpot AI Core: un asistente, catálogo de casos de uso y Jev como clasificador primario

## Statement
El dueño trata con **un solo asistente** (panel, Telegram y canales autorizados). Internamente cada operación de IA
pertenece a un **caso de uso registrado** (`use_case_id`) con prompt versionado, ruta de modelo versionada,
presupuesto y política propios. Ningún caso de uso existe por permiso implícito del modelo: se incorpora al
catálogo, se evalúa y se activa.

Jev (TypeSafe System One) es el **clasificador semántico primario** de mensajes y eventos de texto: intención,
capacidad destino, sentimiento (positivo / neutral / negativo / mixto), categoría, urgencia, señales de riesgo,
necesidad de aclaración e incertidumbre. Jev **no genera, no autoriza y no ejecuta**: identidad, tenant, RBAC,
cuotas, aprobaciones y publicación quedan en el backend. La confianza de Jev no se trata como probabilidad
calibrada salvo evaluación que lo demuestre.

## Acceptance criteria
| id | given / when / then |
|---|---|
| AC-12001 | Given un mensaje del dueño o un evento de texto (comentario, reseña, pedido de edición), when llega, then la clasificación semántica registrada proviene de Jev (fuente `jev`) y la acción, permisos y aprobaciones se deciden en backend (DEC-0066). |
| AC-12002 | Given un negocio `real` y un proveedor cuya cobertura contractual no está verificada, when se pediría esa IA, then no sale ningún dato a ese proveedor, solo ese tratamiento muestra `BLOCKED_EXTERNAL` y las demás capacidades siguen (DEC-0067). |
| AC-12003 | Given una invocación de IA, when termina, then queda registrada con use_case, prompt_version, route_version, proveedor, modelo, latencia, uso/costo con origen y resultado de política. |
| AC-12004 | Given una petición sin caso de uso registrado, o con caso de uso sin ruta activa y sin grant de laboratorio vigente para una ruta DRAFT permitida (DEC-0074, solo `lab`), when se intenta ejecutar IA, then se rechaza (deny-by-default), sin fallback a otra ruta o proveedor. |
| AC-12005 | Given un grant de laboratorio seleccionado, when llega un evento de texto que requiere clasificación, then la clasificación sigue usando la ruta normal de Jev/TypeSafe; el grant nunca sustituye la clasificación ni la decisión de permisos del backend (DEC-0074). |

## Notes / rationale
APR-0003 aprobó este canon (QS-0017/ANS-0017, 2026-11-03). DEC-0066: Jev es el clasificador semántico primario de
todo proceso de texto, con evaluación por capacidad y versión; el gate de DEC-0031/DEC-0033 sigue rigiendo la
intención del dueño. DEC-0067 sustituye a DEC-0019: datos reales hacia TypeSafe tras verificar una vez la cobertura
contractual. DEC-0032 limita TypeSafe a USD 1/día en desarrollo y pruebas. DEC-0074 (SRC-0012, directiva humana
externa): en desarrollo, Anthropic directo genera texto/razonamiento y OpenAI directo solo imágenes; Jev sigue
primario. Las candidatas DRAFT se prueban en runtime por el propietario desde la interfaz bajo un grant de
laboratorio explícito (BR-0007, FR-0019), sin evaluaciones generativas ejecutadas por el agente y sin simular PASS.
