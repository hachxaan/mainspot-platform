# DEC-0042 — Publicación real: MainSpot sirve el sitio publicado en el subdominio; Hostinger solo gestiona el DNS (canon sin cambios)

JSON estructurado (fuente normativa): `DEC-0042.json`. Este Markdown lo acompaña y no es otro registro.

## Decision
Respuesta a Q-HOSTINGER-PUBLISH «Publicación real de sitios: ¿dónde vive el sitio publicado?»: `web_en_mainspot` — «Como dice el canon: MainSpot sirve el sitio publicado en el subdominio y Hostinger solo gestiona el DNS». Condiciones declaradas por la sesión: la vista previa y la aprobación siguen en MainSpot (FLOW-002), cada versión publicada se conserva en la base de datos para poder volver a publicarla y el token de Hostinger sigue fuera del repositorio.

## Options rejected
- hosting_hostinger — Hostinger aloja el sitio publicado: MainSpot crea el subdominio en el hosting, sube el HTML aprobado, lo despliega por API y Hostinger gestiona el SSL
- diferir — Seguir con la publicación simulada por ahora
