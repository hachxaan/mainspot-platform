# DEC-0069 — Política de proveedores del AI Core: TypeSafe directo (Jev), Anthropic directo prioritario para texto, OpenAI directo gpt-image-2 para imágenes; OpenRouter fuera de nuevas ejecuciones y sin fallback

JSON estructurado (fuente normativa): `DEC-0069.json`. Este Markdown lo acompaña y no es otro registro.

## Decision
Respuesta a Q-NOTES «Notas para el registro», §3 (texto íntegro en DEC-0072): TypeSafe directo para clasificación semántica (Jev); Anthropic directo como proveedor prioritario para conversación, razonamiento, redacción, diseño y edición web, publicaciones, respuestas, campañas y demás tareas generativas de texto; OpenAI directo para imágenes con el modelo `gpt-image-2` (en OMP como `openai-codex/gpt-image-2`), comprobando mecanismo de integración y condiciones de acceso antes de incorporarlo como servicio del backend; la disponibilidad de un modelo en OMP no equivale a credenciales API de producción; OpenRouter no se usa en nuevas ejecuciones, ni como intermediario ni como fallback; se conservan los resultados históricos sin mantener OpenRouter como ruta activa; cada caso de uso conserva configuración independiente de modelo, proveedor, prompt, parámetros, presupuesto y evaluación; si Anthropic no alcanza la calidad o presenta incompatibilidades técnicas se pueden evaluar otros proveedores directos.
