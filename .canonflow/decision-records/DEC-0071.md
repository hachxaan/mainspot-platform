# DEC-0071 — Anthropic (texto) y OpenAI (imágenes) pueden procesar datos de negocios reales con las mismas condiciones que TypeSafe en DEC-0067

JSON estructurado (fuente normativa): `DEC-0071.json`. Este Markdown lo acompaña y no es otro registro.

## Decision
Decisión del propietario en la conversación con el agente del 2026-11-03, al resolver la cuestión abierta que dejaba ANS-0017: §2 autoriza datos reales solo para TypeSafe/Jev y §3 asigna Anthropic y OpenAI, mientras BR-0007 bloqueaba datos de negocios reales hacia proveedores generativos. Pregunta del agente: «¿Pueden Anthropic (texto) y OpenAI (imágenes) recibir datos de negocios reales (marca, instrucciones del dueño y texto de comentarios y reseñas de sus clientes)?». Respuesta literal: «Sí, con las condiciones de TypeSafe». Condiciones (las de DEC-0067): verificar una vez los términos comerciales y el acuerdo de tratamiento de datos de la API de cada proveedor (uso para entrenamiento, retención, subencargados); minimización, aislamiento por negocio, acceso autorizado, protección de credenciales, trazabilidad y retención; si algo no queda cubierto se limita solo ese tratamiento. Se registra en esta ingesta por instrucción del propietario de no abrir otra sesión HDC.
