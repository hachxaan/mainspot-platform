# DEC-0074 — Anthropic texto/razonamiento, OpenAI imágenes, Jev primario; ejecución DRAFT solo en laboratorio con grant y aceptación manual

JSON estructurado: `DEC-0074.json`. Fuente literal: `../sources/SRC-0012-anthropic-manual-lab-directive.md`
(sha256 `883591ed8b1bab5658ba6bc81b9522441fc088b6a1ed6040ddbba9fb9346d13a`).

## Decisión

La instrucción explícita del propietario en SRC-0012 sustituye, solo para la configuración actual de desarrollo de MainSpot, la asignación generativa de DEC-0073: Anthropic API directa cubre todas las capacidades generativas de texto y razonamiento; OpenAI API directa conserva únicamente la generación de imágenes para web y redes sociales; TypeSafe/Jev sigue como clasificador semántico primario. Reutilizar adaptadores, Registry, Dispatcher, prompts y rutas existentes: las rutas generativas de texto OpenAI se retiran y se configuran rutas Anthropic correspondientes como revisiones DRAFT; ambos adaptadores permanecen disponibles sin fallback automático y OpenRouter sigue deshabilitado. No se ejecutan evaluaciones generativas pagadas, suites de calidad ni llamadas API de prueba por parte del agente: el propietario prueba personalmente desde la interfaz. Para ello se autoriza ejecutar rutas generativas DRAFT exclusivamente en `AI_ENVIRONMENT=lab` mediante un grant explícito de laboratorio emitido por `platform_admin` o `ai_engineer` con step-up, acotado a tenant, usuario, rutas permitidas, motivo y caducidad, revocable, auditado y sujeto a los presupuestos vigentes; nunca para tráfico normal, nunca por simple pin de ruta ni por cabecera del cliente, y nunca para la clasificación Jev. La aceptación manual del propietario sobre invocaciones reales de laboratorio (evidencia referenciada por invocación, checklist completo, actor y step-up) marca la ruta DRAFT→TESTED en un registro propio de revisión manual, distinto de `ai_eval_run`; no crea evaluaciones ni PASS simulados, no aprueba ni activa por sí misma: aprobación y activación siguen siendo pasos separados con step-up y motivo. Una ruta TESTED por revisión manual solo puede desplegarse en laboratorio; producción sigue exigiendo la suite. Los créditos Anthropic (USD 100 promocionales) y OpenAI son declaraciones del propietario, no verificación independiente; el presupuesto interno generativo de USD 25 acumulados y el de TypeSafe USD 1/día no cambian. Datos reales, aislamiento, idempotencia, circuitos, control de costos y gobernanza existentes se conservan. Esta configuración de desarrollo no decide irreversiblemente el proveedor comercial de producción ni interviene en la investigación comercial independiente.

## Qué sustituye y qué conserva

| Aspecto | DEC-0073 (historia, íntegra) | DEC-0074 (vigente en desarrollo) |
|---|---|---|
| Texto/razonamiento generativo | OpenAI directo (`gpt-6-luna`, `gpt-6.1-sol`) | Anthropic directo (`claude-haiku-5-5` eficiente, `claude-sonnet-5-5` tareas complejas), DRAFT hasta aceptación |
| Imágenes | OpenAI `gpt-image-2` | OpenAI `gpt-image-2` (sin cambio) |
| Clasificación semántica | TypeSafe/Jev primario | TypeSafe/Jev primario (sin cambio; el grant viaja solo como contexto de trazabilidad y nunca autoriza una ruta Jev DRAFT) |
| Adaptadores | Anthropic no operativo | Ambos disponibles; sin fallback; OpenRouter deshabilitado |
| Validación de rutas | Suites reales PASS antes de aprobar | Suites conservadas pero **no ejecutadas por el agente**; en laboratorio, aceptación manual del propietario → TESTED (revisión manual) → aprobar → activar, pasos separados |
| Presupuestos | USD 25 acumulados; TypeSafe USD 1/día | Sin cambio; créditos del proveedor declarados, no verificados |
