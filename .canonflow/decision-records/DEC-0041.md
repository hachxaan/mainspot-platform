# DEC-0041 — Telegram: un bot de MainSpot para todos los negocios; vinculación con enlace de un solo uso, caducable y revocable

JSON estructurado (fuente normativa): `DEC-0041.json`. Este Markdown lo acompaña y no es otro registro.

## Decision
Respuesta a Q-TELEGRAM-MODEL «Canal de Telegram: ¿qué bot se usa y cómo se vincula un chat con un negocio?»: `bot_unico` — «Un bot de MainSpot para todos los negocios; vinculación con enlace de un solo uso generado en el panel (caduca y se puede revocar)». Condiciones declaradas por la sesión para todas las opciones: un chat no vinculado solo recibe instrucciones para vincularse; los mensajes de un chat vinculado entran en el flujo vigente con la identidad y los permisos del usuario vinculado.

## Options rejected
- bot_por_negocio — Un bot por negocio: el propietario lo crea en BotFather y pega el token en el alta; MainSpot lo guarda cifrado y registra un webhook por bot (además hay que vincular quién escribe)
- bot_unico_telefono — Un bot de MainSpot; vinculación compartiendo el teléfono: el bot pide el contacto y lo compara con el teléfono registrado del propietario
