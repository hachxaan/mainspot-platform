# DEC-0068 — Presupuesto de IA generativa: techo acumulado de laboratorio USD 25 incluido el consumo histórico; sin mensualidad ni gasto publicitario; aplicación automática

JSON estructurado (fuente normativa): `DEC-0068.json`. Este Markdown lo acompaña y no es otro registro.

## Decision
Respuesta a Q-AI-BUDGET «¿Qué presupuesto rige la IA generativa (texto e imágenes vía OpenRouter)?»: otro_en_notas — Otro presupuesto (descríbelo en las notas); contenido en Q-NOTES §4: techo de referencia del laboratorio = gasto acumulado máximo de USD 25 en IA generativa, incluido el consumo histórico reportado; no se aprueba mensualidad recurrente ni gasto publicitario; las integraciones directas con Anthropic y OpenAI requieren credenciales autorizadas y controles de consumo; el saldo de OpenRouter no se asume transferible; el presupuesto de TypeSafe (DEC-0032) sigue separado; el sistema aplica el presupuesto automáticamente y las ejecuciones dentro de límites no requieren autorización humana; se registra costo real, modelo, proveedor y caso de uso cuando el proveedor los expone, distinguiendo estimaciones de cargos observados.

## Options rejected
- lab_25_total — USD 25 en total para laboratorio con datos sintéticos; cualquier ampliación en otra sesión
- lab_25_mas_mensual — USD 25 para laboratorio y USD 30 al mes para desarrollo continuo, ambos solo con datos sintéticos
